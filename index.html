Tools I use at work

I built these because I needed them. They run in the browser so you can just open them and get on with it.

DXF Viewer & Exploder
Opens and displays DXF files. Has a button to explode everything down to bare geometry on layer 0 and export it as a clean DXF 2013 file.
CAD
Bar Optimiser
You give it a stock length and a list of cuts and it tells you how many bars you need and how to cut them to keep waste low.
